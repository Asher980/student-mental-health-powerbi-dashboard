# Student Mental Health Analysis Dashboard (Power BI)

## Project Overview
This project explores the relationship between student mental health and academic performance using an interactive Power BI dashboard.

Mental health challenges such as anxiety, depression, and panic attacks can significantly affect students' academic outcomes. This dashboard visualizes patterns across age, course of study, CGPA, and mental health indicators to provide insights into these relationships.

## Objectives
- Analyze the prevalence of depression, anxiety, and panic attacks among students
- Examine how mental health relates to academic performance (CGPA)
- Identify patterns across different courses and age groups
- Create an interactive dashboard for easy exploration of the data

## Dashboard Features
The Power BI dashboard includes:

- Total student count
- Average CGPA
- Depression, anxiety, and panic attack counts
- Depression distribution by course
- Average CGPA by age
- Average CGPA by course
- Panic attacks by CGPA
- Depression count by age
- Interactive slicers (Gender and Marital Status)

## Tools Used
- Power BI

- Data Visualization
- Interactive Dashboard Design

## Key Insights
Some insights observed from the analysis include:

- Certain courses showed higher reported depression counts
- Panic attacks appear more frequently among certain CGPA groups
- Average CGPA varies slightly across courses
- Age groups show different mental health patterns
